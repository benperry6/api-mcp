> #### 根本原因一（致命）：异步 requestHandler 的 Promise 拒绝未处理 → 进程崩溃
>
> **位置**: [src/mcp-server/index.ts:285](src/mcp-server/index.ts#L285)
>
> ```typescript
> // 问题代码：Node.js HTTP server 不会 await 异步 handler，也不 catch Promise 拒绝
> const httpServer = createHttpServer(requestHandler);  // requestHandler 是 async 函数!
> ```
>
> **崩溃触发链**:
> 1. 客户端连接后在 `ensureApiKeySession()` 等待期间断开（ECONNRESET）
> 2. `ensureApiKeySession()` 认证耗时最长 1413ms，远超客户端超时
> 3. 认证结束后执行 `for await (const chunk of req)` 读取 body，但 socket 已关闭
> 4. Node.js HTTP 服务器内部 `abortIncoming` 抛出 `Error: aborted`
> 5. 错误沿 async 函数向上传播为 **unhandled promise rejection**
> 6. **全局无任何 `process.on('unhandledRejection')` / `process.on('uncaughtException')` 保护**（已确认代码中不存在）
> 7. Node.js v22 默认行为: unhandledRejection → triggerUncaughtException → **进程终止**
>
> ---
>
> #### 根本原因二：并发认证请求无互斥锁 → QPS 超限
>
> **位置**: [src/mcp-server/index.ts:44-61](src/mcp-server/index.ts#L44) (`ensureApiKeySession`)
>
> ```typescript
> async function ensureApiKeySession(apiKey: string): Promise<void> {
>   await apiKeyStorage.run(apiKey, async () => {
>     const session = getSession();
>     if (session && ...) return;   // ← TOCTOU 竞态: 多个并发请求同时看到 session=null
>     await createSession(...)      // ← 多个请求并发各自调用一次, 触发 QPS 限制
>   });
> }
> ```
>
> ChatGPT 会在短时间内发起多次 `initialize` 请求，每次均触发 `ensureApiKeySession`，由于**缺少 per-apiKey 的并发锁**，多个认证请求同时命中 CJ API，1秒内超过 1次/秒 的 QPS 限制。
>
> ---
>
> #### 根本原因三：ChatGPT 自身 JWT Token 被误传为 CJ API Key
>
> **表现**: `apiKey=eyJhbGciOiJI…`
>
> `eyJhbGciOiJI` 是 Base64url 编码，解码为 `{"alg":"JH...`，这是标准 JWT 头部特征。
>
> ChatGPT 可能将自身的 OAuth access token 作为 MCP URL 路径参数传入（`/mcp/{jwt}`），服务器将其当作 CJ API Key 去调用认证接口，导致 "APIkey is wrong" (1600005)。
>
> **URL 格式问题**: `/mcp/{anything}` 中所有非 `API@userId@CJ:token` 格式的路径段都被识别为 apiKey，无法区分 CJ API Key 与 JWT。
>
> ---
>
> #### 三个根因优先级
>
> | 优先级 | 根因 | 影响 | 修复思路 |
> |--------|------|------|----------|
> | P0 🔴 | 未捕获 Promise 拒绝 | 进程崩溃，服务完全不可用 | HTTP server 层包装错误捕获 + req 错误处理 |
> | P1 🟡 | 并发认证无锁 | QPS 超限，认证失败 | per-apiKey Promise 去重/互斥锁 |
> | P2 🟢 | JWT 误传为 apiKey | 认证失败，用户配置错误 | URL 解析时检测 JWT 格式并返回明确错误 |
